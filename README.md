# Demo React Form Starter

A React and Vite contact-form starter with name, email, and message fields.

## Getting Started

- Set up a new project

```bash
npx degit colbyfayock/demo-react-form-starter my-react-form
```

- Navigate to your new project

```bash
cd my-react-form
npm install
```

- Start the development server

```bash
npm run dev
```
