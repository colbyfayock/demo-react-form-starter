# Demo React Form Starter

A React/Vite learning landing page with a contact form for name, email, and message; submitting currently only prevents page navigation and sends no data.

## Use this template

```bash
npx degit colbyfayock/demo-react-form-starter my-react-file-upload
```

## Local setup

Install dependencies with npm, then start the development server:

```bash
npm install
npm run dev
```

Use the local URL printed by the development server.

Use `npm run build` to create a production build.
Use `npm run preview` to preview that build.
